Brief explanation
Hallucinot — for once, AI fixes human hallucinations. A team of Drex agents checks every sentence of a live meeting, a document or a chatbot answer against what your organization actually knows, and shows the receipt. Our wildcard proof: Hallucinot is judging the Drexathon itself. HOW IT WORKS • Live meeting: speech → a Drex router classifies each sentence → agents run in parallel, every call made by Drex: Fact checker, Suggest, Action items, Leak guard, Decision recorder, Policy guards auto-created from rules found in your own documents, and custom agents written in plain English. When two agents disagree, a third Drex call arbitrates (negotiation). Each transcript line is colored: verified / wrong / policy flag / changed today / answered / to-do. • Learns with no clicks: remembers decisions announced in the meeting, warns when a later statement contradicts them, learns from self-corrections. • Check any document: chatbot answers, emails, sales flyers, student posters (Adobe Express) — every claim gets checked, with Fix (correct sentence picked from the source) and Cite. • Judge mode: drop any submissions file (CSV/Excel/PDF/screenshot); Drex reviews each row, listens to each team's live demo, detects who is presenting, checks every claim against that team's own repo/slides, and scores all teams on the official rubric with a live big-screen board. HOW WE USED NACE • Drex: every decision — router, all agents, verdicts, fix selection, negotiation, team detection, rubric scoring (~0.3–0.6 s per decision). • NDI (Perception API): parses PDFs, images (OCR), Word, slides and submission files into the knowledge base; rules found in them become new agents. • Intern: meeting recap + action items handed to @Intern in Slack. • Partners: DeepInfra (Llama 3.3 70B) as the "System 2" writer, called only when Drex decides writing is needed; Adobe Express/Firefly for the deck, mascot and classroom poster. EVIDENCE • Drex vs Claude Opus 5.5 on 50 meeting lines over 300 real GitHub PRs: same accuracy (47/50), ~6× faster (0.38 s vs 2.2 s), ~500× cheaper. • Drex-routed vs LLM-on-every-sentence (12-line meeting): 58% fewer LLM calls, ~7× lower LLM cost; the LLM-only design missed the discount-policy break, the leaked API key and the action item. • End-to-end judging test: 15/16 checks passed. All tests are in the repo (eval/).
